Get the app

Install it once and it opens like any other app, works without signal, and can send you notifications later. There is nothing to download from a store.

Detected on your device

Android

Chrome, Edge, Brave or Samsung Internet.

  1. Open iiest.wiki in Chrome.
  2. Chrome usually shows an Install app prompt at the bottom. Tap it.
  3. If it does not appear, tap the ⋮ menu and choose Add to Home screen or Install app.
  4. Confirm. It lands on your home screen with its own icon.

Detected on your device

iPhone and iPad

Safari only. Chrome on iOS cannot install apps.

  1. Open iiest.wiki in Safari.
  2. Tap the Share button, the square with an arrow, at the bottom.
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add.
This step is required for notifications on iOS. Apple only allows a web app to send notifications after it has been added to the home screen, and only on iOS 16.4 or newer. Opening the site in a browser tab will never be enough.

Detected on your device

Windows

Chrome or Edge.

  1. Open iiest.wiki.
  2. Look for the install icon in the address bar, a monitor with a downward arrow, and click it.
  3. Or use the ⋮ menu, then Cast, save and share, then Install page as app.
  4. It gets a Start menu entry and its own window, with no browser chrome.

Detected on your device

Mac

Safari 17 or newer, or Chrome.

  1. Open iiest.wiki.
  2. In Safari, choose File, then Add to Dock.
  3. In Chrome, use the ⋮ menu, then Cast, save and share, then Install page as app.
  4. It appears in Launchpad and the Dock like a normal Mac app.
Open the web app instead

Why there is no store download

This is a progressive web app. The install above gives you the same thing an App Store or Play Store download would: a home screen icon, its own window, offline access and a route to notifications. It updates itself, so you never install a patch, and it takes about 300 KB rather than tens of megabytes.

Attendance you mark without signal is saved on the device and syncs the moment you are back online, so marking in a basement lab is safe.
